# Project Instructions

## Package Manager

Always use `yarn` — never `npm` or `npx`. Run scripts with `yarn <script>`, install with `yarn add`, execute binaries with `yarn <bin>`.

## E2E Tests

- Run all e2e: `yarn cypress run`
- Run single spec: `yarn cypress run --spec cypress/e2e/<file>.cy.ts`
- Open Cypress GUI: `yarn cypress open`
- Start Chopsticks: `yarn chopsticks`
- Dev server: `yarn start`
