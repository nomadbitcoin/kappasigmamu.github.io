### Data-TestID Naming Convention
- Use kebab-case for all test IDs
- Include dynamic values with braces: `{address}`, `{page}`
- For dynamic IDs, use address truncation or page name from route
- Keep IDs semantic and descriptive

### Implementation Pattern
```tsx
// Example: Adding data-testid to a button
<button
  data-testid="connect-wallet-btn"
  onClick={handleConnect}
>
  Connect Wallet
</button>

// Example: Dynamic test ID
<div
  data-testid={`candidate-row-${address}`}
  key={address}
>
  {/* candidate content */}
</div>
```
